# design_system — 主题预设库来源

本目录 60 份主题预设（30 按名 `<类别>/<主题>/design.md` + 30 编号 `0N_<类别>/NN/en/<主题>.md`，两套并行）源自上游 `open-kimi-ppt/reference/design_system`（Kimi-PPT-Skills 仓库），原样保留未改。

- **用法**：用户显式指定某主题时，读对应 `design.md` 作为该 deck 的设计方向（配色/字体/排版基调）。
- **两套结构说明**见上级 `../README.md`「`design_system/` 双结构说明」。
- 本目录为 verbatim 副本，**不参与**与仓库 `docs/` 的同步（`docs/` 无对应文件）。
- 上游若有更新，从上述来源重同步。
